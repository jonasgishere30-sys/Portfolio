# FriedIce portfolio

Single-page portfolio for FriedIce, a Roblox commission developer. Plain HTML, CSS and JavaScript, made for GitHub Pages.

## Files
- `index.html`: the page
- `style.css`: page styles
- `ui.css` and `ui.js`: the game UI section (working shop and live HUD)
- `script.js`: hero sword effects, gallery, lightbox, copy-Discord button
- `images/`: renders (`sword.webp` and `lantern.webp` are transparent cutouts)

## Change the gallery
Edit the `BUILDS` list at the top of `script.js` and put the images in `images/`.
Images that don't load are hidden automatically.

## Put it online
1. Create a public GitHub repo and upload everything in this folder (keep the `images` folder).
2. Settings > Pages > Branch: `main`, folder `/ (root)` > Save.
3. Your site will be at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
